# Paradise Nursery 🌿

Paradise Nursery is a React-based plant shop demo where users can browse houseplants, add products to a shopping cart, update quantities, and remove items.

## Features
- Responsive landing page with a botanical background
- About Us page
- Product listing with plant categories, prices, and images
- Add-to-cart controls and cart item count
- Shopping cart with quantity updates, item removal, subtotals, and total
- Redux Toolkit state management
- React Router navigation

## Technologies
- React
- Vite
- React Router
- Redux Toolkit
- React Redux
- CSS

## Run locally
1. Install Node.js (LTS).
2. Extract this project and open the folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Project structure
- `src/App.jsx` — app shell and route definitions
- `src/App.css` — global styles and landing-page background
- `src/components/AboutUs.jsx` — company information
- `src/features/CartSlice.jsx` — cart reducers
- `src/ProductList.jsx` — product listing page
- `src/CartItem.jsx` — shopping cart page
- `src/app/store.js` — Redux store
- `public/images/` — locally stored botanical background
